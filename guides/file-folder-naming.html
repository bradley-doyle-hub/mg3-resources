File & Folder Naming

How to organise your project files so you can find things. A mess doesn't cost you time or marks later, this does. Works for any tool, any project, in this course or after it.

You will lose track of a file at some point. Everyone does. The question is whether it costs you five seconds or twenty minutes when it happens.

Trust the name, not the timestamp. You won't remember which file was newer just by when it was last saved.

Phases

As a project moves forward, the phase in the file name moves with it.

Motion Test→ Rough Cut→ Fine Cut→ Final Cut

Versions

Numbered, three digits, incrementing: _001, _002, _003...

Don't overwrite a rough cut with a fine cut. Save a new one. Disk space is cheap. Redone work isn't.

Save a new version when:

  1. 1
    Starting a sessionBefore you touch anything, save a backup point.
  2. 2
    Before a major changeAbout to try something that might not work? Save first.
  3. 3
    After a milestoneJust nailed something tricky? Lock it in before you keep going.

The whole system

Name your project folder clearly.
Keep your working files versioned.
Never save over your only copy of something that worked.

That's it. Scales from a five-minute exercise up to a full client project.
