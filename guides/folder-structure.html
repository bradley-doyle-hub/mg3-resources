Folder Structure

What goes inside your project folder, and how to split it up so you can find things.

For how to name the folder and the files in it, see Naming Conventions.

The idea

The project folder itself is just a label. What keeps you organised is how you split up what's inside it.

There's no single correct way to do this. Below is the full version I run on client work, a simplified version built for this course, and one from a completely different discipline, to show the pattern holds no matter what you call things.

A full production structure

This is what I run on client work. More structure than a class project needs, but it's the real thing.

Example project organization
BOC26 - Teaser Animations
Top-level project folder
01_PRE
Everything before you start building
BOARDS
Storyboards, moodboards
REF
Reference material gathered for the project
SCRIPT
Scripts, visual scripts
02_ASSETS
Anything you didn't make yourself, sorted by type
3D
3D models and scenes brought in
AUDIO
Split further by use
_IN
Incoming audio before it's touched
_OUT
Audio exported out of the project
MUSIC
Music tracks
SFX
Sound effects
VOICE
Voice recordings
CAPTURE
Raw voice recordings
CAMERA
Raw camera footage
DESIGN
Design assets
_SLATE
Reusable slate files (16x9, 2x1, social crops, source .ai)
FONT
Fonts used on the project
PHOTO
Photography assets
PROXY
Proxy or optimised media for editing
RENDER
Renders brought in from other software
GUIDE
Reference-only guide renders, not final
STOCK
Stock footage and assets
03_EDIT
Edit software project files
RESOLVE
DaVinci Resolve project folder. Resolve manages it, so leave it alone
04_PROD
Active production. Empty at the start, then add one subfolder per program: AE, C4D, Blender
05_DELIVER
Final exports only. The file you'd hand off

Same five folders, same order, every project. Numbered so it sorts in build order. 02_ASSETS is anything you didn't make. 04_PROD is where you make it. 05_DELIVER is what you hand off.

For this class

What you'll actually use this semester.

Example project organization
Assignment - Project Name
Top-level project folder
01 - Assets
Stock, reference, fonts, audio
02 - Production
Active build files, one subfolder per program
03 - Edit
Renders exported out of your build tool
04 - Delivery
Final exports only

Same logic as the full version. Four folders instead of five, no nested asset library. Incoming material, work in progress, and finished output, kept apart.

A different discipline, same idea

This isn't a motion or 3D pattern. Here's a graphic design project.

Example project organization
ClientName - Brand Refresh
Top-level project folder
00_Brief
Brief, client files, references
01_Assets
Supplied logos, fonts, photography
02_Working
InDesign, Illustrator, Photoshop files, versioned
03_Proofs
Exports for client review
04_Final
Print-ready, final delivery files

Different vocabulary, same three ideas: what came in, what you're building, what's done.

Pick one and stick to it

None of these is the one correct answer.
Pick a structure and keep it consistent.
Don't mix structures mid-project.
